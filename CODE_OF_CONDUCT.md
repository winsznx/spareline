# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique work rather than people, and do not harass anyone. Report unacceptable behaviour privately through GitHub's "Report abuse" option or a private security advisory on this repository. Maintainers will review every report and may remove content or contributors that break these rules.
